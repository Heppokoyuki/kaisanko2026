
# 2026年秋 会山行ロックマラソン 競技規則

## 1. 大会概要

**実施日：** 2026年11月15日（日）  

**開催場所：** 小川山・廻り目平周辺

**競技時間：** <span style="color: red">9:00</span>-16:00

**目的：** フリークライミングを通した会員間の交流、クライミング技術および安全管理意識の共有、モチベーションの向上。

2025年開催の「Rock Marathon by Petzl」を参考に、小川山の各エリアを巡りながら、チームで合計得点を競う。

競技では絶対的な登攀難易度だけでなく、**参加者それぞれの実力に応じた挑戦**を評価する。

競技は当日指定する到着指定地(幕営地付近を指定予定)で開始し、到着をもって終了する。

## 3. 対象ルート

* 2022年フロンティアスピリッツ発行『小川山クライミングガイド』上・中・下に掲載されているフリークライミングルート。
* シングルピッチ、マルチピッチのいずれも対象とする。
* ただし、危険度が高いとみなされる「PD」「R」「X」などの表記があるルートは対象外とする。安全性に疑義があるルートも競技対象としない。
* トラッドルートの場合、プロテクションの事前設置は認めない。安全上プロテクションを事前設置する必要のあるルートは競技対象としない。
* マルチピッチでのフォローの場合、セカンドビレイであってもリードと同等の得点として数える。
* オンサイト/フラッシュ/レッドポイントのスタイルは考慮しない。完登のみを得点とするが、何度トライしても構わない。
* マスタースタイルであるかどうかは考慮しない。
* <span style="color: red">トップロープでの登攀は、得点の対象としない。ただし、事前申告RPグレード以上のルートをトップロープで完登した場合、完登数に数えることができる。トップロープ支点の構築には細心の注意を払うこと。</span>

## 4. 得点計算方法

チーム得点は、各メンバーのルート得点を合計し、マルチピッチ完登ボーナスとエリアポイントを加算して求める。

**ルート得点の計算式**

```text
ルート得点 =
    相対グレード点 × 0.75
  + 絶対グレード点 × 0.25
  + 高さ点
  + トラッドボーナス点
```

### ① 相対グレード点（75%）

* 各参加者の直近2年間の最高RPグレードから4段階下を「想定OSグレード」とする。
* 想定OSグレードを120点とし、登ったルートとのグレード差によって得点を変える。

```text
相対グレード点 = 120 + 20 × Δ
```

Δは、登ったルートが想定OSグレードより何段階上または下かを表す。

| 想定OSとの差 | 相対グレード点 |
|---|---:|
| -4段階 | 40 |
| -3段階 | 60 |
| -2段階 | 80 |
| -1段階 | 100 |
| 同等 | 120 |
| +1段階 | 140 |
| +2段階 | 160 |
| +3段階 | 180 |
| +4段階 | 200 |
| +5段階 | 220 |

* 相対グレード点は最低0点とする。
* 最高RPから4段階下が5.8未満になる参加者については、想定OSグレードを5.8とする。
* トラッドの経験がない場合には、トラッドの想定OSグレードを5.8とします。安全に十分配慮してトライしてください。

### ② 絶対グレード点（25%）

ルート自体の難易度を評価する点数。以下の表を使用する。

| グレード | 点数 |
|---|---:|
| 5.5 | 40 |
| 5.6 | 50 |
| 5.7 | 60 |
| 5.8 | 70 |
| 5.9 | 80 |
| 5.10a | 90 |
| 5.10b | 100 |
| 5.10c | 110 |
| 5.10d | 120 |
| 5.11a | 135 |
| 5.11b | 150 |
| 5.11c | 165 |
| 5.11d | 180 |
| 5.12a | 200 |
| 5.12b | 220 |
| 5.12c | 240 |
| 5.12d | 260 |
| 5.13a | 280 |

5.13b以上については、必要に応じて20点刻みで延長する。

### ③ 高さ点

ルートの高さ1mにつき1点を加算する。

例：20mのルートは+20点。

### ④ トラッドボーナス

| ルートタイプ | 加点 |
|---|---:|
| トラッド | +20点 |
| ミックス | +10点 |
| スポート | なし |

* トラッドとは、カムやナッツなどのリムーバブルプロテクションを使用するルートを指す。
* ミックスとは、カムやナッツなどのリムーバブルプロテクションと既設ボルトを併用するルートを指す。

### 計算例

**最高RPが5.11aの参加者が、5.10b・高さ20mのトラッドルートを完登した場合**

- 想定OSグレード：5.10a
- 相対グレード点：140点（想定OSより1段階上）
- 絶対グレード点：100点
- 高さ点：20点
- トラッドボーナス：20点

```text
140 × 0.75 + 100 × 0.25 + 20 + 20
= 170点
```

## 5. マルチピッチ

全ピッチを登攀し、予定された終了点に到達したチームには、次の完登ボーナスを与える。

| ピッチ数 | 完登ボーナス |
|---|---:|
| 2P | +50 |
| 3P | +100 |
| 4P | +150 |
| 5〜6P | +200 |
| 7P以上 | +300 |

- 完登ボーナスはチームにつき1回のみ。

## 6. エリアポイント

* 各エリアに設定されたポイントを、初めて訪れて対象ルートを1本以上完登した際に加算する。
* エリアポイントは各チームにつき、同じエリアで1回のみ獲得できる。
* 具体的なエリア区分とポイントは別途配布するエリアマップに定める。

## 7. 完登数とチーム得点

各メンバーの完登数に制限は設けない。ただし、特定のメンバーだけが大量に登る戦略を抑え、全員の登攀機会を促すため、**チーム内の最少完登数を超えるルートについては、得点の25%のみ計上する。**

- 最少完登数までは各メンバーのルート得点を100%計上する。
- 超過分は25%計上する。
- 100%計上するルートは、各メンバーの獲得点が高い順に選ぶ。
- <span style="color: red">事前申告RPグレード以上のルートをトップロープで完登した場合、完登数に算入することができる。</span>
- マルチピッチ完登ボーナスとエリアポイントは、この補正の対象外とする。

### 計算例

3人の完登数が8本・5本・5本の場合：

- 全員の上位5本は100%計上する。
- 8本登ったメンバーの残り3本は25%計上する。

各ルート・各ピッチの得点は、1人につき競技期間中1回のみ獲得できる。

## 8. ペナルティ

競技の終了時刻に到着指定地に間に合わなかった場合、遅延時間に応じたペナルティが生じます。
* 0分以上5分未満で-300ポイント
* 以降5分ごとに300ポイント減点

## 9. 安全管理

* 大会本部を設置しないため、各チームの自主的な安全管理を基本とする。
* チームレスキューで収まらない事故発生時は、通常の登山と同じく警察または消防への通報後、留守本部と会山行LINEへの連絡。
* 連絡を確認したチームから競技を終了して、廻り目平キャンプ場へ集合し対応について協議する。

### 競技開始前

- 予定エリア・予定ルート・帰着予定時刻を共有する。
- 各チームで装備・天候・ルート状況を確認する。

### 競技中

- チーム単位で行動し、単独行動はしない。
- 大幅な行動計画の変更は、通信可能な範囲で共有する。
- 危険な登攀や無理な行動を避ける。

### 競技終了時

- 事前に定めた共通帰着時刻までに集合場所へ帰着する。
- 全チームの帰着を相互に確認する。

得点よりも安全を優先し、余裕を持った行動計画と下降を心がける。
